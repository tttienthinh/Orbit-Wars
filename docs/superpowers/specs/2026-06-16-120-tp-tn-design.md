# 120-TP_TN Notebook Design

**Date:** 2026-06-16  
**Notebook:** `120-TP_TN.ipynb`

## Goal

Compare two trained GNN checkpoints on the fixed test episode set by plotting their ROC curves and computing TP/TN metrics at both a fixed threshold (0.5) and an optimal threshold selected via max-F1 on a training sample.

## Models

| Label | Checkpoint |
|---|---|
| `117-GNN` | `117-NewGNN/model_epoch82.pt` |
| `119-Cosine` | `119-NewGNN_Cosine/model_epoch30.pt` |

Both use `OrbitGNN(hidden_dim=64, num_layers=3)` — identical architecture, different training regimes.

## Test Set

Fixed `TEST_EPISODE_IDS` (same 8 episodes as used in 119 training):
```
{78867640, 78899068, 78982947, 79033183, 79126912, 79175592, 79228392, 79320069}
```

## Notebook Sections

### 1. Imports + Model Class
Copy `OrbitGNN`, `build_graph`, `build_attack_pairs`, `evaluate_episode`, `_compute_metrics` verbatim from `119-NewGNN_Cosine.py`. No modifications needed — both checkpoints share the same class.

### 2. Load Both Models
Instantiate `OrbitGNN(hidden_dim=64, num_layers=3)` twice. Load state dicts from the two checkpoint paths. Set both to `eval()` mode.

### 3. Test-Set Inference
Run `evaluate_episode` on all 8 `TEST_EPISODE_IDS` directories under `114-precompute/`. Accumulate `(scores, labels)` lists for each model.

### 4. ROC AUC Plot
Single `matplotlib` figure with two ROC curves (one per model). Label each with its AUC value in the legend. Axes: FPR (x) vs TPR (y). Include the diagonal reference line.

### 5. Threshold = 0.5 Metrics
Print a summary table for each model:

| Model | N_pos | N_neg | TP | TN |
|---|---|---|---|---|
| 117-GNN | … | … | … | … |
| 119-Cosine | … | … | … | … |

### 6. Threshold Selection (Max F1 on 8 Train Episodes)
- Collect all non-test episode dirs; take the **first 8** as the threshold-calibration set.
- Run `evaluate_episode` on those 8 episodes for each model (no-grad, no augmentation).
- Sweep thresholds from 0.01 to 0.99 in steps of 0.01; pick the value that maximises F1 = 2TP / (2TP + FP + FN).
- Each model gets its own optimal threshold (they may differ).
- Print chosen threshold per model, then recompute TP / TN on the **test set** at that threshold and display alongside the 0.5 results.

## Data Flow

```

         │

evaluate_episode(ep_dir, model)
    → (loss, scores, labels)
         │
    ┌────┴────────────┐
    │                 │
ROC curve       TP/TN table
(test set)      (0.5 + opt threshold)
```

## Constraints

- No training occurs in this notebook — inference only.
- No augmentation applied during evaluation (matches `evaluate_episode` contract).
- Threshold sweep is over train episodes only; final TP/TN numbers always reported on test episodes.
- If a test episode raises an exception, skip it and log a warning (matches existing error-handling pattern).
